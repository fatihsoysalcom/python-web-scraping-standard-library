# Python Web Scraping Standard Library

This example demonstrates basic web scraping and parsing using only Python's standard library. It fetches the HTML content of a Wikipedia page and extracts the page title and the first paragraph of text using `urllib.request` for fetching and regular expressions (`re`) for parsing.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
